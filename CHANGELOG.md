# Changelog

## 1.0.0 (Unreleased)

Initial release of the LynxDB data source.

- Config editor for URL, encrypted token, and field mapping.
- Health check against the LynxDB /health endpoint.
- Lynx Flow / SPL2 query editor with field and value autocomplete, parse
  validation, and example help.
- Logs, metrics (timechart), and table results, with grouped timechart pivoted
  to wide series.
- Log-volume histogram and live tail in Explore.
- Annotation queries, ad-hoc filters, and log context.
- Template variables: fields, sources, and values(field).
- Grafana Alerting support and advisory query lints shown as panel notices.
